# Mi Plan de Jubilación

Calculadora interactiva de jubilación y libertad financiera desarrollada con **React**, **TypeScript**, **Tailwind CSS** y **Recharts**.
Forma parte del curso de educación financiera *"El Juego del Dinero: Aprendé las reglas antes de que jueguen con vos"*.

## 🚀 Despliegue en Netlify

El proyecto ya cuenta con el archivo `netlify.toml` preconfigurado:
- **Build command:** `npm run build`
- **Publish directory:** `dist`

### Pasos rápidos:
1. Subí este repositorio a tu cuenta de **GitHub**.
2. Ingresá a [Netlify](https://app.netlify.com/) y seleccioná **"Add new site"** > **"Import an existing project"**.
3. Elegí **GitHub** y seleccioná este repositorio.
4. Netlify detectará automáticamente la configuración (`npm run build` y directorio `dist`).
5. Hacé clic en **"Deploy site"** y tu aplicación estará online en menos de 1 minuto.

## 💻 Desarrollo local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar versión de producción
npm run build
```
